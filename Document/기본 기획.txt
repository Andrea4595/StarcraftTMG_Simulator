스타크래프트 미니어처 게임의 시뮬레이터를 개발하고자 한다.
궁극적으로 게임 한 판을 온전히 플레이 가능한 환경을 구현하고자 하며,
비주얼적인 요소는 배제한다.

게임의 실제 규칙은 '룰북.pdf'를 확인하면 되며,
향후 다루게 될 '미션카드.pdf' 파일도 있다.

탑뷰 시점에서 베이스를 배치하고, 유닛을 옮기고, 주사위를 굴리고 처리한다.


목표 1. 메뉴얼한 베이스 이동 시뮬레이터
- 미션 생성 화면
	- 지형 배치 기능
		- 게임을 시작하기 전, 먼저 지형을 배치할 수 있다.
		- 지형은 정해진 모듈이 제공된다.
		- 지형은 size 값을 가진다.
		- 화면 한 쪽에 보여지는 지형 모듈 목록에서 특정 지형 모듈 클릭 시 해당 모듈의 배치 모드가 된다. 빈 땅을 클릭하면 해당 지형이 배치된다.
		- 배치된 지형을 드래그하여 움직일 수 있다.
		- 지형은 지도 밖으로 벗어날 수 없다.
		- 배치된 지형을 우클릭 하면 다이얼 메뉴가 나온다.
			- 다이얼 메뉴에서는 '삭제', '회전' 기능을 제공한다.
	- 배치구역 설정 기능
		- 지도 가장자리의 특정 영역을 A 또는 B 플레이어의 배치구역으로 지정해줄 수 있다.
	- 미션 목표 배치 기능
		- 지도의 특정 영역에 미션 목표를 배치할 수 있다. 미션 목표는 1~5까지 있다.

- 게임 화면
	- 모델 메뉴얼 이동
		- 아무 모델을 왼 클릭 하여 드래그하면 이동시킬 수 있다.
		- 이 이동은 코헤런시 규칙이나 기타 모든 규칙을 무시하고 수행될 수 있다.
		- 아직 구현되지 않은 기능에 대처하기 위한 임시 기능이다.
	- 다이얼 메뉴
		- 유닛 우클릭 시 다이얼 메뉴가 유닛 옆에 보여진다.
			a. 데미지 기록
			b. 이 모델 제거
			c. 이 모델 복제(같은 유닛으로 포함 됨)
			d. 이 모델을 리딩 모델로 하여 '유닛 이동' 시작
		- 빈 땅 우클릭 시 다이얼 메뉴가 클릭한 자리 옆에 보여진다.
			e. 여기에 베이스 생성
	- 데미지 처리
		- 다이얼 메뉴에서 a로 시작한다.
		- 유닛이 받은 피해를 기록할 수 있다. 단순히 숫자를 입력하는 기능이다.
	- 유닛 이동
		- 다이얼 메뉴에서 d로 시작한다. 해당 모델이 리딩 모델이 되어 이동을 수행한다.
			- 우클릭 시 리딩 모델의 이동이 취소되어 되돌아간다.
		- 지정된 이동 거리만큼 이동, 이후 나머지 모델들을 리딩 모델로부터 코헤런시 거리 이내에 재배치할 수 있다.
			- 리딩 모델 이동 종료 후, 코헤런시 거리 만큼 가이드라인이 그려진다.
			- 가이드라인 영역 내 빈 땅을 클릭 시 아직 재배치되지 않은 아무 모델 하나가 해당 위치로 이동하고, 드래그하는 동안 계속 위치가 갱신된다.
			- 클릭을 떼면 해당 위치로 확정된다.
			- 가이드라인 영역 내 동일 유닛의 모델 클릭 시 해당 모델의 위치를 다시 이동시킬 수 있다.
			- 우클릭 시 모든 배치가 취소되며, 리딩 모델의 이동으로 되돌아간다.
	- 유닛 배치
		- 화면 한 쪽의 아직 배치되지 않은 유닛을 선택하면 배치가 시작된다. 배치된 베이스에 자동으로 이름이 부여되고, 플레이어 색이 칠해진다.
		- 리딩 모델을 게임의 규칙에 따라 설정된 배치 영역(지도 가장자리, 또는 특정 유닛의 베이스)에 바짝 붙여서, 혹은 배치 영역으로부터 이동 가능한 이동거리 이내에 완전히 들어오게 배치할 수 있다. 이후 남은 모델들을 주변에 배치한다. (즉 출발점이 자유로운 '유닛 이동' 기능을 수행하는 셈)
	- 베이스 생성
		- 다이얼 메뉴에서 e로 시작한다.
		- 베이스의 이름 입력 창이 뜬다.
		- 베이스 사이즈 입력 창이 뜨며, mm 단위로 입력한다.
		- 베이스의 팀을 선택한다. 플레이어 A/B 또는 중립을 선택할 수 있다.
		- 베이스가 생성된다.
	- 베이스 제어 기능
		- 베이스를 배치하거나 움직이는 모든 경우에 활용된다.
		- 베이스는 원형 또는 타원형이다.
		- 베이스 끼리 절대로 겹쳐질 수 없다.
		- 베이스는 맵 밖으로 나갈 수 없다.
		- 모델(베이스)을 움직일 때, 마우스 위치에 다른 베이스가 존재한다면 자동으로 해당 위치에서 가장 가까운 아무 베이스와 겹치지 않는 위치에 배치된다.
			- 단, 모델 메뉴얼 이동 또는 리딩 모델 이동 중에는 '변위' 속성을 지닌 베이스 위에 배치될 수 있다.
			  이 경우, 모델 이동이 종료된 즉시 다음 절차 이전에 변위 베이스를 자신과 겹쳐지게 된 베이스로부터 원하는 거리 0" 위치에 배치하는 과정을 거친다.
	- 점수 기록 기능
		- 화면 상단에 라운드, 서플라이, 양 플레이어 각각의 미션 VP, 양 플레이어 각각의 파괴 VP, 양 플레이어 각각의 미션 + 파괴 종합 VP를 보여주는 전광판이 있다.
		- 목표 1에서는 라운드, 서플라이, 각각의 미션 및 파괴 VP를 직접 수정하는 정도로 기능을 제공한다.
